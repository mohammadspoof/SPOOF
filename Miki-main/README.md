## نصب (یک خط، بدون وابستگی)

روی هر سرور اوبنتو ۲۲ یا ۲۴ این خط را بزن؛ خودش باینری را از گیت‌هاب می‌کِشد و نصاب بالا می‌آید:

```bash
curl -fL https://raw.githubusercontent.com/amirm505k1-crypto/Miki/main/miki-linux-amd64 -o /usr/local/bin/miki && chmod +x /usr/local/bin/miki && miki
```

نصاب تعاملی می‌پرسد: پورت پنل، نام کاربری، رمز (هر چیزی، حتی یک حرف)، آیپی سرور (Enter = خودکار) و SSL. در پایان آدرس پنل و نام کاربری و رمز را نشان می‌دهد.

## میکی چیست؟

میکی یک تانل شبکه با پنل وب فارسیِ راست‌چین است که چند ترنسپورت را در یک برنامه‌ی واحد جمع کرده و برای عبور پایدار در شرایط سخت و فیلتر طراحی شده. همه‌چیز داخل یک باینریِ مستقل است؛ نه دانلودی از اینترنت لازم دارد، نه وابستگیِ بیرونی.

## امکانات

- **مدیریت چند سرور** و همگام‌سازی همتاها از یک پنل.
- **چند ترنسپورت:** 6to4، IPIP، GRE، SIT، VXLAN، Geneve، WireGuard، TCP و TLS.
- **ترنسپورت و تست مسیر Spoof:** حملِ ترافیک با مبدأ جعلی برای عبور در فیلتر شدید؛ روی سرورِ وصل خودکار روی هر دو طرف ساخته می‌شود.
- **نمایش زنده‌ی ترافیک** و آمار مصرف هر تانل، با وضعیت واقعیِ «وصل / قطع».
- **تست سرعت، پینگ، جیتر و Packet Loss.**
- **محدودیت سرعت، سهمیه‌ی ماهانه و Smart Queue.**
- **فوروارد پورت** با حالت‌های NAT، Transparent، Proxy و Relay.
- **فایروال و کنترل دسترسی.**
- **بهینه‌سازی شبکه با BBR** و تنظیم بافرها.
- **اندازه‌گیری و تنظیم MTU** و ردیابی مسیر دوطرفه با MTR.
- **ربات تلگرام:** توکن را در پنل وارد می‌کنی و همه‌ی رویدادها را می‌فرستد.
- **تولید دستورات MikroTik RouterOS v7.**
- **راه‌اندازی آفلاین و سرویس خودکار systemd** — ری‌استارت خودکار بعد از کرش یا ریبوت.
- **تاریخچه‌ی تغییرات و بازگشت به نسخه‌ی قبل.**

## وصل‌کردن دو سرور

میکی را روی سرور دوم هم با همان دستور نصب کن، بعد روی سرور اصلی:

```bash
sudo miki peer add <نام> --address <آیپی-سرور-دوم>
```

یا از داخل پنل: صفحه‌ی «سرورها» → «افزودن سرور».

## حذف کامل

```bash
sudo miki uninstall -y
```
